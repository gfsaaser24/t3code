# Markdown files

T3 Turbo recognizes Markdown files linked in agent messages and can open them without leaving the conversation.

- Click or Ctrl-click a Markdown file link to open it in the file side panel.
- Ctrl+Shift-click a Markdown file link to open it with the default Markdown application on the machine running the connected T3 server.

Choose the side panel's default presentation under **Settings > T3 Turbo Settings > Markdown file preview**:

- **Pretty** renders the document with Markdown formatting.
- **Code** shows the editable Markdown source.

The Pretty/Code button in the file panel changes the same preference, so the setting stays consistent across projects and threads.
