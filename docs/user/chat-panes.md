# Chat panes

T3 Turbo can keep several chats visible in one workspace. Each pane keeps its own thread header,
worktree and Git controls, composer, terminal, and file or preview panel.

- Right-click a thread card and choose **Open in split pane to the left** or **Open in split pane to
  the right**.
- Use the `+` menu in a chat header to start a new chat on either side.
- Use the close action in that menu to remove the current pane. The final pane stays open.
- Click or focus a pane before using a keyboard shortcut. Global chat, terminal, preview, and
  composer commands apply only to the focused pane.

T3 Turbo saves the ordered pane references in client settings and restores them on reload. Chats,
messages, connections, and diff workers are not copied into the layout record. Local web,
desktop, and hosted or relay-connected web clients use the same pane behavior.
